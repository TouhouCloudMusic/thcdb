- UID.（数据类型为bigint）
- ID（类型为varchar，大小为16）

- 用于找回的A.（数据类型为varchar，大小为128）

## 注册、登录、注销、找回
### 注册
提供账户的`ID`、`密码`、`一组Q&A`进行注册，内部工作如下：
- `提供的ID`在表中唯一，否则返回`ID_not_unique`
- `密码`经过哈希加盐后储存.
- 主权限为`comment,gain_permission,object_rectify,create_personal_list`.
- 将Q储存进`用于找回的Q`，A经过哈希加盐后储存进`用于找回的A`.
### 登录
提供`ID`和`密码`进行登录，内部工作如下：
- 检查注销情况，如果已注销，则不可登录，返回`was_delete_account`.
- 将`提供的密码`与`提供的ID对应的账户`的`密码`比对，如果相同则登录账户.
### 注销
提供`UID`进行注销，内部工作如下：
- 如果`UID`不存在，则返回`no_account`.
- 将`UID对应账户的注销`的设为注销时的10位UNIX时间戳.
### 找回
找回分为修改密码和找回账户.
#### 找回账户
提供`ID`、`密码`、`用于找回的A`进行找回账户，工作流如下：
- 找不到账户则返回`no_account`.
- `提供的用于找回的A`和`提供的密码`分别与`提供的ID`对应的`用于找回的A`和`密码`相同，则清空这个账户的`注销`.
#### 修改密码
提供`ID`、`用于找回的A`、`修改后的密码`修改密码，工作流如下：
- 找不到账户或账户已注销则返回`no_account`.
- `提供的用于找回的A`和`提供的ID`对应的`用于找回的A`相同，则将`修改后的密码`覆盖`提供的ID`的`密码`.
### 补充
注销时间超过90天的账户清空登陆凭证、权限、ID.
部分操作需要登录，每次登录寿命为24h，超时需重新登录.
